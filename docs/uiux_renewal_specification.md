# vibeCodeEase: UI/UX リニューアル仕様書 (AI版全コードのサイドバー表示)

## 1. コアコンセプト
- **2ペインによる非侵入型の学習体験:**
  - **左側 (作業場):** ユーザーが手元でコーディングを行うVS Code標準のテキストエディタ。
  - **右側 (AIワークスペース):** VS Codeのサイドバー（Webviewパネル）領域に、**AIがブラッシュアップした後の「コード全体」**を提示・可視化する。
- ユーザーは手元で一通り作業を終えた後、「ふと右側のサイドバーを見る」ことで、AIによるコード全体のブラッシュアップ結果と、どこが悪かったのかの指摘を学べる。

## 2. サイドバーパネル (右側) のUI要件
- **AI改善済みの全コード表示:**
  - サイドバー領域内に Monaco Editor (または類似のコードビューア) を埋め込み、AIが修正したソースコードの**全量**を美しくシンタックスハイライトして表示する。
  - サイドバーの狭い横幅に対応するため、ビューアは `wordWrap: 'on'`（右端折り返し）等の設定を行い、横スクロールによるストレスを軽減する。
- **差分ハイライトと指摘リスト（学習フィードバック）:**
  - AI版の全コードの中で、ユーザーの手元コードから変更された行（AIが修正・追加した箇所）は、背景色等で視覚的にハイライトされる。
  - 変更行をクリック（またはホバー/アイコン押下）すると、インラインポップオーバー等で「AIによる変更理由・設計の改善ポイント（指摘事項）」が表示される。
- **設定画面の隔離:**
  - パネル上部のヘッダー（「⚙️」アイコン等）を使って、AIワークスペース表示と、既存の設定画面（Painマトリクス等）の表示をトグル切り替え可能にし、レビュー画面を広く保つ。

## 3. インタラクションとデータ同期要件
- **ユーザー To AIワークスペース (即時反映):**
  - ユーザーが手元でファイルをセーブしたタイミング等で、即座にサイドバー側のAIのベースコードが同期され、最新のユーザーコードをもとにしたブラッシュアップが実行・反映される。
- **AI To ユーザーワークスペース (適用):**
  - **個別適用:** コメントポップオーバー内の「✨ 適用」ボタンを押すことで、その特定の修正だけをユーザーの手元コードに反映できる。
  - **一括適用:** パネル上部の「🚀 すべて適用」ボタンを押すことで、表示中のAI提案すべてを手元のコードへ反映できる。
