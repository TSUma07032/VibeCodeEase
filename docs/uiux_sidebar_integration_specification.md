# vibeCodeEase: サイドバー「AIワークスペース統合」仕様書

## 1. プロジェクトの目的と背景
前回のフェーズで実装した「AIワークスペースの可視化」をさらに洗練させる。VS Code標準のDiffエディタを利用するアプローチから脱却し、拡張機能のサイドバー（Webview）内にAIワークスペースを完全に統合する。これにより、ユーザーのメインエディタ領域を占有しない、純粋な非侵入型の学習・レビュー体験を提供する。

## 2. UI / UX レイアウト仕様
サイドバーのメイン画面を「AIレビュー画面」として再定義する。
以前サイドバーに存在した設定画面（Painマトリクス等）は、サイドバー上部の「⚙️ 設定アイコン」等から別画面（ルーティング変更やモーダル等）として逃がし、メインのスペースをレビュー体験に全振りする。

### AIレビュー画面の構成
*   **ファイルセレクタ:** 現在AIが解析・ブラッシュアップを行っているファイル（変更があるファイル）を選択できるUI（ヘッダー部分のプルダウン等）。
*   **コードビューア (ミニエディタ埋め込み):**
    *   選択されたファイルの**「全コード（AI版）」**を綺麗にシンタックスハイライトして表示する。Monaco Editor等のコード表示用コンポーネントを活用する。
    *   ユーザーの手元のコードから変更された行（AIの提案箇所）は、背景色や装飾等で明確にハイライトされる。
*   **学習支援コメント:**
    *   変更行の付近（またはインライン）に、AIの変更理由・設計の改善ポイント等の解説が表示される。

## 3. 適用（Apply）のインタラクション仕様
ユーザーがAIの提案を学習し、手元のコードに反映するための手段として以下の2つを提供する。

1.  **個別適用 (✨ Apply):** 
    各変更箇所（ハイライト行やコメントUI内）に配置されるボタン。クリックすると、その特定のスニペットだけが手元のユーザーエディタ（実際のファイル）に即座に反映される。
2.  **一括適用 (🚀 Apply All):**
    サイドバーの上部等に配置されるボタン。クリックすると、現在表示中のファイルに対するAIの提案（変更箇所すべて）が手元のファイルに一括で反映される。

## 4. データの同期 (継続要件)
ユーザーが手元のエディタでファイルを保存・編集した場合、即座にサイドバー側の「AIワークスペース」のベース状態が同期され、常に最新のユーザーコードとAI提案が比較・表示される状態を維持する。
