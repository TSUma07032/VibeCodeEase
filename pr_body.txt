💡 実施内容 (What):
- `src/core/editorDecorator.ts` の `onDidChangeTextDocument` および `SharedAnalysisCache` のイベントリスナーにおける装飾の更新処理に対して、デバウンス（Debounce）処理を追加しました。

🎯 理由・目的 (Why):
- ユーザーが高速にテキストを入力した際に、既存のタイマーをクリアせずに新しい `setTimeout` を多数登録してしまい、重複した無駄な装飾更新処理が走り、メインスレッドを圧迫する可能性があったためです。

📊 影響 (Impact):
- 100回の連続イベント発火時の処理回数を100回（約150.36ms）から1回（約151.61ms）へと大幅に削減し、不要な計算とUIフリーズを防ぎます。

🔬 検証方法 (Measurement):
- `npm run lint`, `npm run compile`, `xvfb-run -a npm test` がすべてパスすることを確認済みです。
